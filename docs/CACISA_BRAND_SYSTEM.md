# Cacisa Systems Brand System

This is the working source of truth for Cacisa's public and product-facing
visual language. It is intentionally short: a useful system should prevent
drift without becoming a manual that people avoid using.

## Brand sentence

**Cacisa Systems makes institutional reasoning legible.**

Cacisa is the company. The Institutional Reasoning Engine is its reusable core
technology. Higher education is the first implementation domain. `From Opacity
to Legibility` is the research and public-interest programme.

Public material must not imply that Cacisa authors an institution's policy,
makes an institution's final decision, or has a live institutional deployment
unless that is established and approved for publication.

## Mark

Use the selected C-frame mark consistently. It is a structural expression of a
reasoning path, not a decorative motif. The mark used by the public site is
`company-site/assets/cacisa-symbol.png`.

Do not introduce alternate AI-generated symbols, starbursts, dot clusters,
circuits, shields, brains, chat bubbles, or abstract "AI" flourishes alongside
the mark. A future professional vector master may refine the mark, but it must
replace the asset everywhere as one deliberate identity update.

## Colour roles

| Role | Hex | Use |
| --- | --- | --- |
| Cacisa Graphite | `#405262` | Primary structure, headings, frames |
| Ink | `#17212B` | High-contrast text and dark surfaces |
| Teal | `#00A89A` | Reasoning path, active explanation |
| Green | `#00C784` | Confirmed or accepted information |
| Coral | `#FF6B5E` | Conflict, attention, review route |
| Amber | `#F3B33D` | Provisional state or implementation emphasis |
| Paper | `#FCF7ED` | Warm primary surface |
| Cloud | `#F2F5F7` | Quiet secondary surface |
| Slate | `#718096` | Secondary text |

Colour communicates a role, never the whole message. A status must also carry
a written label and a familiar non-colour cue.

## Type and composition

- Use Inter (with a standard system fallback) for interface and body text.
- Use a restrained editorial serif only for rare long-form or presentation
  contexts, never as a substitute for a product hierarchy.
- Favour full-width bands, structured paths, clear grids and generous spacing.
- Use one primary focal point per section. Repeat the mark only when it identifies
  an owned surface, not as background filler.
- Do not use gradients, floating glass cards, bokeh/orbs, stock-like imagery or
  generic technology diagrams.

## Public versus product surfaces

The public site may explain Cacisa and use only synthetic or approved material.
It never hosts institutional sign-in, real records, tenant cookies or
behavioural tracking. Tenant and provider surfaces follow the same semantic
colour roles but use their own identity, data and deployment boundaries; see
[Online Presence](CACISA_ONLINE_PRESENCE.md).

## Pre-publication check

Before introducing a public visual or page, ask:

1. Does it use the selected mark, rather than an unrelated substitute?
2. Does every colour have a meaningful role?
3. Does it explain Cacisa without inventing a customer, result or capability?
4. Does it keep company, provider, institution and governed-person boundaries
   intelligible?
5. Would it still read as Cacisa if the logo were temporarily hidden?
